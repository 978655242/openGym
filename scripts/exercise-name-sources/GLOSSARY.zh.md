# Simplified Chinese exercise-name terminology

- Use concise, natural Simplified Chinese titles used by Chinese-speaking gym-goers.
- Preserve the movement, equipment, posture, grip, direction, side, assisted/weighted status, and all qualifiers from the source title.
- Translate equipment consistently: barbell = 杠铃; dumbbell = 哑铃; kettlebell = 壶铃; cable = 拉力器/绳索 (prefer 拉力器 in machine names); resistance band = 弹力带; Smith machine = 史密斯机; stability ball = 瑜伽球; medicine ball = 药球; body weight = 自重; suspension trainer = 悬挂训练带.
- Prefer standard movement terms: squat = 深蹲; deadlift = 硬拉; bench press = 卧推; overhead press = 推举; row = 划船/划船动作; pulldown = 下拉; pull-up/chin-up = 引体向上/反手引体向上; push-up = 俯卧撑; dip = 臂屈伸; curl = 弯举; extension = 伸展/伸展动作; raise = 抬腿/提举 according to the body part; lunge = 弓步; crunch = 卷腹; calf raise = 提踵; fly = 飞鸟; shrug = 耸肩; plank = 平板支撑.
- Translate "assisted" as 辅助 and "weighted" as 负重. Do not confuse an assisted movement with a weighted movement.
- Keep proper nouns and established exercise names (e.g. Pilates, Burpee, Turkish Get-Up) in their commonly used Chinese form; include an English term only when that term is commonly used or needed to distinguish the movement.
- Return sentence-style Chinese with no final punctuation and no English title appended; the app adds the canonical English title separately when that setting is enabled.
- Do not repair or reinterpret questionable source mechanics; translate the title faithfully. Use body-part, equipment, and target metadata only to disambiguate.
